Net Monitor Pro — شريط مراقبة سرعة الإنترنت
=============================================

المتطلبات:
    pip install psutil

التشغيل:
    python net_monitor.py

آخر التطويرات (حسب طلبك):
- تم تقليل الشفافية الافتراضية لتكون واضحة ومريحة للمراقبة (0.97 بدل 0.90)،
  مع تعطيل "الشفافية الحقيقية" على ويندوز افتراضيًا حتى لا تختفي الخلفية.
- تمت إضافة زرّي "تصغير (–)" و"إغلاق (×)" ظاهرين دائمًا في أعلى يمين
  الشريط، بدل الاعتماد على النقر المزدوج أو زر الفأرة الأيمن فقط.
- عجلة الفأرة فوق الشريط تتحكم بمستوى الشفافية مباشرة (تكبير/تصغير الشفافية
  حسب رغبتك، ويُحفظ آخر إعداد تلقائيًا).
- إضافة إجمالي البيانات المستهلكة في الجلسة الحالية (Total) لكل من الرفع
  والتنزيل، بوحدات ذكية (KB/MB/GB).
- الوضع المصغّر أصبح شريطًا رفيعًا بسطر واحد يعرض الأرقام فقط، مع زر إظهار
  (▢) بدل زر التصغير للرجوع للوضع الكامل.
- يتم حفظ الموضع + مستوى الشفافية + حالة التصغير تلقائيًا، وتُستعاد جميعها
  عند إعادة التشغيل.

طريقة الاستخدام:
- اسحب الشريط من أي مكان فيه (عدا الأزرار) لتحريكه.
- اضغط زر "–" لتصغير الشريط، واضغط "▢" في الوضع المصغّر للرجوع للوضع الكامل.
- اضغط زر "×" لإغلاق الأداة.
- مرّر عجلة الفأرة فوق الشريط لزيادة/إنقاص الشفافية.

ملاحظات:
- يمكن تفعيل "الشفافية الحقيقية" (اختفاء الخلفية تمامًا على ويندوز) عبر
  تغيير المتغيّر self.true_transparency_enabled إلى True في الكود، لكنها
  معطّلة افتراضيًا الآن حسب ملاحظتك بأن الشفافية الزائدة تصعّب المراقبة.
- يمكن تعديل الألوان والأحجام من أعلى الملف (BG، UP_COLOR، DOWN_COLOR،
  DEFAULT_ALPHA... إلخ).

أفكار لتطوير إضافي لاحقًا (أخبرني إن أردت أيًا منها):
- عرض اسم واجهة الشبكة النشطة (Wi-Fi / Ethernet) والانتقال بينها.
- تنبيه صوتي أو بصري عند تجاوز سرعة معينة.
- رسم بياني موحّد (Up+Down) بدل رسمين منفصلين لتوفير المساحة.
- قائمة بزر يمين الفأرة (Right-click menu) بدل الإغلاق المباشر: تحتوي
  خيارات مثل "إعادة تعيين الإحصائيات"، "دائمًا في الأعلى: تشغيل/إيقاف".
